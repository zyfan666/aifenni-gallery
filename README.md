# 爱分你 · 纸上来信微型画廊（24 幅版）

最新范围依据：2026-11-06 用户继续制作指令与 `项目规划/13-24幅画廊与演示认购纪念卡.md`。在既有实现上调整，保留首页、纸白墨绿、1/2 标志、翻面、画框、弹层和 hash 路由。旧版手机号表单、独立支付、库存/售罄和电子证书已移除。

当前结构：

```text
首页 → 三行画廊（24 幅，三行各 8 幅，全部向右）→ 作品详情
  ├─ 分享这幅画 → 普通作品分享卡 → 下载图片／复制作品链接
  └─ 体验认购 → 规格、选填昵称与演示确认 → 本地处理中
                  → 预计支持去向 → 个人作品纪念卡 → 下载／分享／继续浏览
```

无需认购即可浏览和分享。所有认购均为课堂演示，不扣款、不收手机号、地址或真实支付信息，不代表原作售卖或版权转让。

## 安装、启动与构建

环境要求：Node.js 22.12+，npm 10+。本次实际使用 Node 26.8.2 / npm 11.19.1。

```sh
cd aifenni-gallery
npm ci
npm run dev
```

开发入口：[http://127.0.0.1:5173/](http://127.0.0.1:5173/)。不要双击 HTML。

```sh
npm test
npm run build
npm run preview
```

生产构建本机预览：[http://127.0.0.1:4173/aifenni-gallery/](http://127.0.0.1:4173/aifenni-gallery/)。源码与素材完整保存在本目录，构建产物为 `dist/`，运行不依赖项目原作目录。服务均绑定本机环回地址；重启电脑或退出进程后需重新启动，端口冲突时先关闭旧实例或另行指定端口。公开网站不依赖本机服务。

React 19.2.0、Vite 7.3.7、qrcode 1.5.4、sharp 0.35.5，依赖由 package-lock.json 锁定。没有后端或真实交易接口。

## 代码与资源

- `src/Home.jsx`：从既有实现抽出的“纸上来信”首页，保留同画开场、翻面和展签。
- `src/Gallery.jsx`：三行各 8 幅原作，加视觉循环副本；完整目录只有 24 个唯一可访问作品链接。画框不堆认购按钮。
- `src/main.jsx`：页面与弹层组织、详情、路由焦点和浏览位置恢复、按作品保留的会话草稿与纪念信息。
- `src/Experience.jsx`：规格与演示确认、处理中/防重复/取消、完成反馈、预计分配、纪念卡。
- `src/ExportCard.jsx`：普通分享与纪念卡共用的异步生成、实际 PNG 下载、复制与受限替代反馈，两类内容独立。
- `src/poster.js`：普通分享卡与纪念卡宽 1080px、高度按作品比例和文字内容适配；真实画作完整铺满内容内宽，正式域名确定后接 QR。
- `src/components.jsx`：既有 Logo、支持失败重试的作品图片、弹层焦点循环、分配金额、来源明确的项目背景。
- `src/data.js`：24 幅作品与来源、三行划分、集中规格价格（整数分）、分配计算、选填昵称校验、草稿与纪念快照。
- `src/router.js`、`src/config.js`：作品/认购/纪念页 hash 解析、正式 HTTPS 配置与作品链接。
- `src/styles.css`：沿用设计变量、响应式、可见焦点、安全区域、文字放大和减少动态规则。
- `public/art/thumb/`：画框、目录和订单式摘要使用的缩略图，最长边不超过 360px；清晰图在 `public/art/`，详情/制卡时按需加载。
- `素材映射.json`：24 个源文件、画名、画者、原作编号、行号、版本说明、原作 SHA-256 与衍生图路径。
- `scripts/prepare-art.mjs`：从课程原作等比生成两档 WebP；原作不修改。重生成需保留项目原作目录，普通运行不需要。

## 操作与状态

- 画廊三行全部从左向右，提供暂停/继续、手动完整目录。鼠标在画框、触摸操作、作品焦点、详情/弹层或页面后台时暂停相关运动；“继续”按钮不会被自身焦点阻止。系统减少动态效果下仍能浏览 24 幅。
- 详情完整看画、放大细节、来源编号、普通分享和演示认购是独立入口。缺图会显示反馈，可恢复网络后重新载入。
- 艺术版画演示 ¥99，明信片演示 ¥29；价格与实体规格是课堂方案。可选昵称最多 12 个字符，留空为“爱画的朋友”。不要求注册或真实个人信息。
- 规格、昵称与确认状态按作品保留在 React 内存中，取消返回不串用。切换规格需重新确认。处理中可取消；重复确认被禁用按钮和同步锁拦截；离开清除计时器。
- 完成页先说明预计支持去向：50% 画者稿酬、30% 课程基金、20% 制作与物流。以分计算，合计与演示金额一致，明确未扣款、比例未核实；制作物流不是公益捐款。
- 纪念卡包含作品、作者、昵称、演示规格、上海时区日期、DEMO 本地纪念编号，以及“演示认购纪念，不构成付款或捐赠证明”。它不是订单、官方公益凭证、限量或版权证书。
- 打开普通海报仅反馈“作品分享卡已生成”；复制 API 成功后才反馈已复制，失败提供可选中的链接；点击下载仅反馈已请求下载/图片预览，不能保证已写入相册。
- 制卡或图片导出失败可重试，保留当前作品和纪念信息。断网提示不承诺首次离线可用，没有新增离线缓存。
- 不使用 localStorage、sessionStorage、cookies 或服务端持久化个人输入。刷新/关闭后清空；刷新纪念页没有会话快照时给重新体验入口。

作品例：[http://127.0.0.1:4173/#/work/garden](http://127.0.0.1:4173/#/work/garden)。作品可直接访问、刷新、前进/后退，再继续逛画廊。旧 checkout/pay/certificate URL 收敛到相应作品详情，不恢复旧交易流程。

正式入口：https://zyfan666.github.io/aifenni-gallery/

源码仓库：https://github.com/zyfan666/aifenni-gallery

仓库只保存本站源码、运行素材和开发夹具；课程原始材料与报告不上传。作品素材用于本课程展示，仓库公开不表示授予素材再利用或版权转让。

GitHub Pages 由 `.github/workflows/deploy.yml` 自动发布：推送 `main` 后执行 `npm ci`、测试、构建，上传且仅上传 `dist/`。Pages 设置使用 **GitHub Actions**。构建地址来自 `actions/configure-pages` 的实际输出，自动写入站点和二维码；本地生产构建默认读取 `.env.production` 中的同一地址。

重新部署：修改源码后提交并推送 `main`，在仓库 Actions 查看发布结果。回退时对错误提交执行 `git revert` 并推送；不要强制覆盖历史。不要更改仓库名或 Pages 地址，否则已经印制的吊牌二维码会失效。

开发模式仍使用本机链接。生产构建用于 Pages 子目录；预览时访问 `http://127.0.0.1:4173/aifenni-gallery/`。如需临时生成根路径的本地演示构建，可运行 `VITE_BASE_PATH=/ VITE_PUBLIC_SITE_URL= npm run build`。

正式二维码导出：

```sh
node scripts/export-qrcodes.mjs https://zyfan666.github.io/aifenni-gallery/ ../最终提交/链接与二维码
```

该命令导出网站入口及 24 幅作品对应的 PNG、SVG、JSON 与 CSV。正式地址接入说明：

1. 复制 `.env.example` 为 `.env.local`，将 `VITE_PUBLIC_SITE_URL` 填为已确定、实际可访问的公开 HTTPS 地址；不要填示例域名或密钥。
2. 子目录部署时，`VITE_BASE_PATH`（如 `/gallery/`）与公开地址中的子目录必须一致。
3. 重新构建，只发布 `dist/`。此目录不包含课件、XLSX、原始 ZIP、个人输入或开发故障夹具。
4. 无有效公开地址时，PNG 显示“扫码入口待发布”；有有效地址时，QR 编码当前作品独立 URL，接入点在 config.js / poster.js。
5. 部署后检查真实 QR 内容、微信/相机、蜂窝网络、长画名、24 幅直达、刷新与返回、图片长按保存、免登录访问。本机 localhost 不能当作老师可访问的地址。

## 自检夹具与交接

`npm test` 验证素材唯一性、缩略图、整数分分配、选填昵称、纪念快照、草稿隔离、路由和公开地址约束。必要浏览器检查记录位于项目 `测试与证据/24幅调整/`。

开发服务器专用夹具（不进入 dist）：

- `tests/browser-fixtures.html`：通过可见的“开发检查场景”切换图片缺失、Canvas 导出失败、剪贴板拒绝、断网状态/图片加载失败，再恢复正常。仅用于执行异常 UI，不能冒充真实系统网络/权限设置。
- `tests/reduced-motion.html`：模拟 matchMedia 的 reduce 分支，不改变系统设置。
- `tests/text-scale.html`：将根字号设为 32px，验证 200% 文字。
